## Problem

#75 第一輪驗證發現，綱要 skill 照字面執行時有幾處做不到或不安全，規格也有幾條規則留了缺口。

- skill 的指令靠 shell 變數，而變數不會從一個指令留到下一個。作者回覆之後，確認的動作找不到當初給他看的那一份。
- 反推與起草時，寫入檢查讀的是正式的綱要檔，而這時候綱要還在暫存目錄，正式的檔還不存在。
- 確認一段的開頭文字只出現一次，用的是算行數：同一行出現兩次會被當成唯一；開頭文字要跨到下一行才唯一時，永遠通不過。
- 稿件的文字被放進 shell 的雙引號裡，一般的 LaTeX（錢字號、反斜線、反引號）會被改掉或被當成指令執行。
- 來源指標可以指到 repo 以外的檔，前提檢查的 agent 會去讀並引用出來。它的 brief 也沒有說讀到的內容是資料、它只讀不寫。
- 不要、刪掉或搬動一節時，沒有處理它底下的節：那些節的 parent 會指不到任何紀錄，或指到後面的行。
- 確認紀錄檔最後一行沒有換行時，追加會把兩筆接在同一行。
- 一筆紀錄用 uses 指到被標成不要的段落時，前提檢查不會回報。
- 其他較小的缺口：狀態比的是文字而不是 JSON 的值；部分確認可能寫出沒有任何節的紀錄；作者點選對話框的選項算不算明說沒有寫；沒有可執行檢查的理由寫成做不到，實際是延後。

## Root Cause

第一版的 skill 由獨立讀者盲讀、也當成文件審過，但它的指令從來沒有照 skill 實際執行的方式跑過：一次一個指令，裡面放真的稿件文字。節底下的節、依賴被標成不要的紀錄、確認紀錄檔的最後一行，這三處沒有規則，是因為沒有例子用到它們。

## Proposed Solution

照 spec delta 修改 article-outline 這個 capability，skill 與說明文件跟著改。規則的選法是一條規則消掉一類問題。

- 稿件、綱要檔與作者的文字只經由檔案進入指令；檢查要指令明說成功才算通過。（新增一條 requirement。）
- skill 的每一個指令都從同一組寫明的路徑開始；給作者看的那一份留在 repo 以外的檔裡，不見了就重新給他看。
- 開頭文字算的是它在檔案文字裡出現幾次，連續的空白（含換行）算一個空格，所以可以跨到下一行。
- 來源指標的檔必須在 repo 裡；skill 自己解析每個路徑、數 label 與開頭文字，第六種結果每次都用同一種方式判定，另外五種由 agent 依解析得到的檔判斷。
- 一節是文章的一部分時，它的 parent 一定指到前面、也是文章一部分的節；沒有任何紀錄指到一節時才刪掉它。
- 確認紀錄由給作者看的那一份組成，至少涵蓋一節，statement 是作者自己打的字，追加時自成一行。
- 狀態用 JSON 的值判定。一節一節確認之後還需要一次整份的確認，狀態會說出來。
- 節與段落紀錄的字串不含控制字元；LaTeX 的反斜線寫進 JSON 時沒有寫成兩個，有幾種情況會變成控制字元。

## Non-Goals

- 照綱要把文字寫進稿件，以及比對寫出來的文字與綱要（#75 Expected 第 2 條與第 5 條的重寫）。這兩項要不要移到 #51 由維護者決定，這個 change 不處理。
- 綱要檔的機械檢查與各條 requirement 的可執行測試。延後到 #78（排在 Swift package #46 之後）。skill 的指令維持為呼叫現成工具的指令列，之後由 #78 的命令列工具取代。
- 綱要的段落與結構附檔的段落怎麼對起來、承諾能不能先在綱要上排、同一段的要點之間要不要標關係。說明文件把它們列為這一版沒有回答的問題。
- 確認紀錄不記是誰通過的。說明文件寫明這個限制。

## Success Criteria

- skill 裡每一段指令，各自在一個新的 shell 裡、只帶 skill 要求重寫的那幾行路徑，對一份測試稿件實跑。測試稿件的文字含有錢字號加括號、反引號、反斜線、引號、同一行重複的句子、開頭相同的兩個證明。這些文字沒有任何一部分被執行或被改寫，每個檢查只在成立時印出成功的那一行。
- 確認的指令在下列情況不追加任何東西：給作者看之後檔案改過、給他看的那一份不見了、沒有點名任何一節、點名的節沒有給他看過、statement 是空的。確認紀錄檔不存在、或最後一行沒有換行時，追加的紀錄自成一行。
- 來源指標的檔指到 repo 以外（開頭是斜線、兩個點、symbolic link）時被擋下，不讀。
- 一筆紀錄的鍵換了順序、或 1 寫成 1.0 時，狀態的結果不變；一節一節確認之後，狀態回報還需要一次整份的確認。
- 全套 pytest 通過；這張 issue 不碰的三個目錄（plugin 的 scripts、tschema-check plugin、tests）相對於 main 沒有變動。
- 只拿到說明文件的讀者，對改過的規則的題目答得和預存的答案相同。
